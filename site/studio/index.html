Enter the studio key

Paste the key you were given and this browser remembers it. You do this once on each computer, then the studio just works.

The key stays in this browser and is only ever sent to GitHub. On a computer that is not yours, press Sign out when you are done.

Don't have the key? (for whoever runs the shop)
  1. Make a key on GitHub (it opens with the name filled in).
  2. Under Repository access pick Only select repositories, then true-offline.
  3. Under Permissions, Repository permissions, set Contents to Read and write.
  4. Press Generate token, copy it, and share it with whoever helps run the shop. Each person pastes it above.

Add a piece

Open the listing on Etsy and press your Add to True Offline button. The photos are cut out, the size chart is read and the piece joins the site, made the same way as the rest.

Once on each computer

Drag this button up to your bookmarks bar. If the bar is hidden, show it from your browser's View menu.

Add to True Offline
Every time

Paste the listing's link to open it, then press Add to True Offline in your bookmarks bar.
